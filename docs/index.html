02Three surfaces, one tree

The default surface is Html: plain text with Jinja's braces. Pug reads indentation; Markdown is the brace surface with whitespace presets a markdown file expects. A block switches language anywhere:

{{ n }}
{% block lang=pug %}p doubled: #{n * 2}{% endblock %}

Blocks nest recursively and keep the variables around them. With force = true a language the outer surface does not speak stays literal text, markers and all.

03Jinja2, whole

Every statement, all 51 filters, all 30 tests, the six globals, the complete loop object, three undefined policies (strict by default), whitespace control, line statements, and the i18n extension over a translate seam. Nothing on the checklist is missing.

04Django's pages, Jinja's hand

The capability set fills the gaps with Jinja's spelling: {% empty %} is {% else %}, block.super is super(), the colon filter spelling is refused, and the supplement filters — date, slugify, yesno, json_script… — carry Django's own semantics.

05Yours, through the same door

Filters, tests, globals and the loader are traits. Everything built in registers through them; your code registers through the same four. Host knowledge — url(), csrf_token(), now() — enters as globals the caller registers, the way Flask registers url_for.
