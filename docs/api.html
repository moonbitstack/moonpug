moonpug/spec

Values and the contract extensions build on: objects, filters, tests, refusals. The engine re-exports what a caller needs.

suberror Refused

Why a template could not be read or rendered. Every variant names the template and the one-based line it stopped at; a fault raised by an extension carries an empty name and line 0 until the engine fills in where it was called from.

pub(all) suberror Refused {
  Syntax(template~ : String, line~ : Int32, column~ : Int32, reason~ : String)
  Unknown(template~ : String, line~ : Int32, kind~ : String, name~ : String)
  Invalid(template~ : String, line~ : Int32, reason~ : String)
  Exceeded(template~ : String, line~ : Int32, limit~ : Int32, got~ : Int32)
} derive(Eq, @debug.Debug)
Syntax

The source is not well formed.

Unknown

A name that resolves to nothing: a variable under the strict policy, a filter, a test, a template, an attribute. kind says which.

Invalid

The source is well formed and the values do not fit: wrong arguments, a type an operation does not take.

Exceeded

A bound in Limits was crossed.

enum Undefined

What happens when an undefined value is used, Jinja's three answers: Lenient prints nothing and iterates as empty but refuses attribute access; Chainable also lets attributes of it be undefined in turn; Strict refuses every use except asking whether it is defined.

pub(all) enum Undefined {
  Lenient
  Chainable
  Strict
} derive(Eq)

trait Object

A host value a template can use. Each method is optional: an object that only has attributes implements attr, a function only call. Cyclers, macros, namespaces and the loop variable are objects too.

pub(open) trait Object {
  fn kind(Self) -> String
  fn attr(Self, String) -> Value? = _
  fn call(Self, Call, Array[Value], Map[String, Value]) -> Value raise Refused = _
  fn callable(Self) -> Bool = _
  fn assign(Self, String, Value) -> Unit raise Refused = _
  fn show(Self) -> String = _
  fn items(Self) -> Array[Value]? = _
}
kind

What messages call it: "a cycler", "the macro row".

attr

call

obj(args).

callable

Whether call does anything; the callable test asks this.

assign

{% set obj.name = value %}.

show

What {{ obj }} prints.

items

What a loop over it walks; None when it cannot be iterated.

Line

The line in the template where the following node starts.

Raw

Output never escaped: the indentation syntax's != and !{…}.

For

A loop. each is the indentation syntax's: with two names the value binds first, then the index or key.

Include

raw includes the text as it stands, as the indentation syntax does for a file that is not a template. inline renders the file in place, as the indentation syntax does: what it defines stays defined and its blocks take part in inheritance. block is the indentation syntax's body under an include, rendered where the included file says yield.

Yield

Where an include's block goes.
