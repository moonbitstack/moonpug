Reference

Built-ins

What a template can reach without being handed anything: the filters, tests and globals, and the statements that shape a page. Every live example below is rendered by the same engine this site is built from — edit nothing, the output is the real one.

Filters

Seventy-nine filters, written after a value with |. Aliases are noted where they stand in for another.

Text and letters

filter capitalize

Capitalise the first character and lowercase the rest.

value|capitalize
template
{{ "hello WORLD"|capitalize }}
output
Hello world

filter capfirst

Capitalise only the first character, leaving the rest.

value|capfirst
template
{{ "hello"|capfirst }}
output
Hello

filter center

Centre the text in a field of the given width.

value|center(width)
width int
field width
template
{{ "hi"|center(10) }}
output
hi

filter cut

Remove every occurrence of a substring.

value|cut(arg)
arg string
text to remove
template
{{ "a-b-c"|cut("-") }}
output
abc

filter escape

Escape HTML so the text is safe to write. Markup is left as it stands.

value|escape
template
{{ "<b>"|escape }}
output
&lt;b&gt;

filter e

An alias of escape.

value|e
template
{{ "<b>"|e }}
output
&lt;b&gt;

filter escapejs

Escape text so it is safe inside a JavaScript string.

value|escapejs
template
{{ "a'b<c"|escapejs }}
output
a\u0027b\u003Cc

filter forceescape

Escape even text already marked safe.

value|forceescape
template
{{ ("<b>"|safe)|forceescape }}
output
&lt;b&gt;

filter indent

Indent each line (after the first unless first) by a width.

value|indent(width, first, blank)
width int or string
spaces or a literal prefix
first bool
indent the first line too
blank bool
indent blank lines too
template
{{ "a\nb"|indent(2) }}
output
a b

Statements

The tags that shape a template. Most run live below through the same engine this site ships; a few that need a loader or a host object are shown with their syntax.

Flow control

statement if

Branch on a condition; elif adds a clause, else the fallback.

{% if cond %}…{% elif cond %}…{% else %}…{% endif %}
template
{% if n > 2 %}big{% elif n == 2 %}two{% else %}small{% endif %}
data
{"n":2}
output
two

statement for

Loop over items. The else runs when there were none; break and continue work inside. The loop variable holds index, index0, revindex, first, last, length, depth, previtem, nextitem, cycle(…) and changed(…); a recursive loop calls loop(children).

{% for x in items %}…{% else %}…{% endfor %}
items sequence
what to iterate
if condition
loop only matching items
recursive flag
descend into nested items
template
{% for x in items %}{{ loop.index }}:{{ x }}{% if not loop.last %}, {% endif %}{% else %}none{% endfor %}
data
{"items":["a","b","c"]}
output
1:a, 2:b, 3:c

statement set

Bind a name to a value, or to a block of markup with endset.

{% set name = expr %} · {% set name %}…{% endset %}
name name
the variable
expr value
a value or filter chain
block flag
a block form with endset
template
{% set greeting %}Hello {{ name }}{% endset %}{{ greeting }}
data
{"name":"Ada"}
output
Hello Ada

statement with

Give names local values for the enclosed block.

{% with a = 1, b = 2 %}…{% endwith %}
names assignments
names and their values
template
{% with total = 3 %}{{ total }}{% endwith %}
output
3

Templates and reuse

statement macro

Define a reusable block with parameters; call it by name, or with a caller block via endcall.

{% macro name(args) %}…{% endmacro %} · {% call name(args) %}…{% endcall %}
args parameters
names, defaults, a rest parameter
template
{% macro field(n, v="") %}<input name="{{ n }}" value="{{ v }}">{% endmacro %}{{ field("q") }}
output
<input name="q" value="">

statement filter

Apply a filter to a block of markup.

{% filter upper %}…{% endfilter %}
filter filter
the filter and its arguments
template

data

statement block

Define a named block a parent can fill; super() calls the parent's block, scoped sees the loop around it, required must be filled, append and prepend add to it. The indentation syntax has block append and block prepend too. Needs a loader through Env::new(load=…).

{% extends "base" %} · {% block name %}…{% endblock %}
template
{% extends "layout.html" %}
{% block body %}page{% endblock %}

Inheritance needs a loader, so the example below is shown, not run. The parent is read through load passed to Env::new; the Guide walks a full layout.

statement include

raw flag
include as text

{% include "footer.html" ignore missing %}

Includes a named template through the loader, so the syntax is shown rather than run here.
